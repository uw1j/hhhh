🚀 البدء السريع

من الصفحة الرئيسية يمكنك إنشاء مشروع جديد، أو فتح مشروع محفوظ، أو استيراد ملفاتك. اختر Code Lab من القائمة الجانبية لبدء كتابة الأكواد، أو Image Lab للتصميم.

💻 Code Lab - اللغات المدعومة

✅ لغات قابلة للتشغيل فعلياً:
• HTML + CSS + JavaScript — تُشغَّل مباشرة في المعاينة الحية.
• Python — يُشغَّل عبر Pyodide (يتطلب اتصال بالإنترنت أول مرة).

✏️ لغات للتحرير فقط (بدون تنفيذ):
TypeScript, Java, C, C++, C#, PHP, SQL, JSON, XML, Markdown, Go, Rust, Kotlin.
هذه اللغات تحتاج مترجمات خارجية لا يمكن تشغيلها بالكامل داخل المتصفح. عند محاولة تشغيلها ستظهر رسالة واضحة بالسبب.

⌨️ اختصارات لوحة المفاتيح

Ctrl+S — حفظ الملف الحالي
Ctrl+N — ملف جديد
Ctrl+F — بحث داخل المحرر
Ctrl+H — بحث واستبدال
Ctrl+/ — تعليق السطر
F5 أو Ctrl+Enter — تشغيل الكود
Ctrl+Z — تراجع   Ctrl+Y — إعادة

🎨 Image Lab - نصائح

استورد صورة أو ابدأ بقماش فارغ. أضف نصوص وأشكال، نظّمها عبر الطبقات، صدّر النتيجة بصيغة PNG أو JPG.

🔒 الخصوصية والميزات التي تحتاج إنترنت

كل ملفاتك تُحفَظ محلياً في متصفحك (IndexedDB) ولا تُرسَل لأي خادم.
ميزات تحتاج إنترنت: تحميل مكتبة CodeMirror، تحميل محرك Pyodide لتشغيل Python، تحميل أيقونات Font Awesome.
إذا لم يتوفر إنترنت، سيعمل التطبيق بوضع احتياطي بسيط.

❓ أسئلة شائعة

هل يمكن تشغيل Java أو C++؟
لا يمكن حالياً داخل المتصفح بدون خادم. يمكنك تحرير الأكواد وتنزيلها واستخدام محرر خارجي للتشغيل.

أين تُحفظ ملفاتي؟
في IndexedDB داخل متصفحك على نفس الجهاز. استخدم "نسخة احتياطية" لنقلها بين الأجهزة.
